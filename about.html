System Design & Methodology

Technical Architecture

A zero-cost, serverless, modular front-end application built strictly with vanilla standards (HTML5, CSS3, ES6+ modules) and explainable deterministic decision models.

End-to-End System Architecture

The application operates entirely within the user's web browser. All external communication is initiated via standard asynchronous HTTP fetch() requests wrapped with 10-second AbortController timeouts and resilient fallback cascades.

Integrated Open APIs

All third-party services utilized operate strictly within their free tiers and public community guidelines.

Project Objectives & Privacy Mandate

Zero-Cost Architecture

Entirely serverless and free-tier compliant. Designed to run on static file servers without compute fees or cloud hosting overhead.

Transparent & Explainable AI

Replaces opaque black-box deep learning models with a deterministic, auditable scoring rule set. Commuters always know exactly why an advisory was issued.

Zero Telemetry Privacy

No cookies, tracking scripts, or analytics beacons. GPS coordinates are kept exclusively in memory during the active session.

No registration. No tracking. All processing happens in your browser.
